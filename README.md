# Stickers

This is our first project developed together with ChatGPT — **Stickers**.

The project is an online store where users can choose stickers they like either from the catalog or create stickers based on their own images.

The core idea is simple: **take only what you need, and don't take what is usually added as an unnecessary extra.**

The goal of the project is to help users express and emphasize their individuality through a wide variety of images presented as physical stickers.
## Project status

The project is under active development.

### September 21, 2026

- Work on the public start page has begun.
- The catalog, search filters, sticker selection and multi-sheet order layout are being developed and tested.
- The first original sticker collection is being assembled around **Cheddar**, an orange cat character.
- Print margins, cutting gaps and plotter constraints are being incorporated into the sheet-layout model.
- The checkout flow is being designed before account, payment and production integrations are added.

The artwork and production image files are prepared separately and are not published in this repository. GitHub is used for the project code, documentation and development history.
