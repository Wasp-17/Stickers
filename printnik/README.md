# Печатник

Локальная Windows-программа проекта «Наклейки» для подготовки листов к печати и контурной резке.

## Первый прототип

Прототип не меняет исходник. Он создаёт отдельный производственный пакет:

- `cleaned.png` — изображение без наружной белой подложки;
- `print_with_bleed.png` — печатный слой с цветовым запасом за линией реза;
- `cut.svg` — векторная линия реза;
- `comparison.png` — крупное сравнение исходника, результата и линии реза;
- `manifest.json` — параметры и контрольные суммы результата.

Запуск из корня проекта:

```powershell
python -m printnik.prototype prepare --input "путь-к-картинке.png" --output "папка-результата" --asset-id RK17-0023 --size B
```

Для запуска из исходников нужны Python 3.11+, Pillow и NumPy. Готовый `dist/Printnik-Setup.exe` не требует отдельной установки Python.

## Испытания 20–21 октября 2026 года

- Подтверждена печать на Epson EcoTank L8050 и контурная резка на Silhouette Cameo 5 Alpha по USB.
- Успешно проверены размеры A и B, регистрационные метки и сложные внешние контуры с тонкими соединёнными деталями.
- Работает опытная подготовка отдельного изображения и прототип распределения целых заказов между несколькими устройствами.
- Результаты резки по размерам и видам контура записаны в `docs/CALIBRATION_LOG.md`.

## Печатник 0.3

Собраны автономные файлы `dist/Printnik.exe` и `dist/Printnik-Setup.exe`. Реализованы ручные и импортируемые заказы, постоянная очередь, защита от повторной печати, масочная компоновка с поворотом, профили материалов, заметные внутренние отверстия A–E, техническая маркировка листов, назначение оборудования, аварийный перенос, конверты, звуковая тревога и мост к Silhouette Studio. Добавлен A1 (35 мм), отдельные правила размера по ID и обязательный просмотр всех линий реза на каждом листе. Производственным файлом служит MASTER либо ART; WEB не выбирается. Для бесплатной Silhouette Basic готовится пробный DXF, физический масштаб которого ещё предстоит проверить. Длина линий реза считается по листам и после подтверждения добавляется к счётчику установленного ножа.

Руководство оператора: `docs/OPERATOR_GUIDE.md`. Текущее обновление и следующая проверка: `docs/UPGRADE_2026-10-23.md`.

## Важное ограничение

Автоматический контур пока является кандидатом для проверки, а не разрешением на автономную резку. После калибровки Cameo 5 Alpha утверждённые сочетания «тип контура + размер + материал» смогут обрабатываться без подтверждения.
