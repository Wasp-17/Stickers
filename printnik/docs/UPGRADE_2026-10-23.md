# Печатник 0.3 — согласованное обновление

- Производственный файл выбирается по ID только среди MASTER и ART, с приоритетом MASTER. WEB и исходные PNG не служат запасным вариантом.
- Полностью или почти полностью непрозрачный файл не проходит как фигурная наклейка. Прямоугольник допускается только после отдельного выбора оператором.
- A остаётся 30 × 30 мм, A1 добавлен как 35 × 35 мм. Печатник не увеличивает заказ молча. Правило A для конкретного ID находится в `catalog-data/cut_size_rules.json`; пустой список означает, что индивидуальные ограничения ещё не утверждены. При сборке тот же список включается в Печатник.
- Каждый лист имеет крупный предпросмотр печати с наложенными красными линиями всех резов. Перед печатью и резкой требуется утверждение оператором.
- Для Silhouette Studio Basic создаётся пробный DXF с контурами и контрольными габаритами в `job.json`. Импорт DXF может менять физический масштаб и положение, поэтому прямой рез без проверки в Studio не разрешён. SVG сохраняется как векторный эталон, но Basic его не открывает.
- PDF открывается для печати вне Silhouette Studio; оператор задаёт параметры Epson и подтверждает фактическую печать. Профиль испытанной глянцевой самоклейки: стандартное качество, сила 12, скорость 4, вылет ножа 2, один проход. Это результат последнего опыта, а не универсальная калибровка.

## Следующая физическая проверка

На пробном листе импортировать DXF в Basic, сверить его габариты и положение с `cut_bounds_mm`, выставить A4 без коврика и метки 10/10/10/25 мм, затем проверить совпадение реза с печатью. До такой проверки и сохранения рабочего `.studio3` сквозной путь печать → резка не считается готовым.

Отдельные капли, автоматическое распределение по бумаге, размер F и правила конкретных рисунков пока не утверждены.
