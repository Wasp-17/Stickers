# Профиль печати и резки

## Зафиксированные размеры

Размер означает наружную рамку готовой наклейки по будущей линии реза. Рисунок
вписывается в неё пропорционально, без растяжения.

| Код | Максимальная рамка |
| --- | --- |
| A | 30 x 30 мм |
| B | 50 x 50 мм |
| C | 75 x 75 мм |
| D | 100 x 100 мм |
| E | 125 x 125 мм |
| F | Вся откалиброванная рабочая область A4 |

Для квадратного или круглого изображения обе стороны достигают размера рамки.
Для вертикального или горизонтального изображения длинная сторона достигает
предела, а короткая определяется исходными пропорциями.

## Оборудование

- Принтер: Epson EcoTank L8050.
- Планируемый режущий плоттер: Silhouette Cameo 5 Alpha.
- До калибровки поля листа, техническая зона и расстояния между резами остаются
  предварительными.

## Контур наклейки

Размер измеряется по внешней линии реза, включая окантовку. Прозрачный холст
исходного PNG в размер не входит.

Для изображений с кляксоподобным краем и отдельными каплями нельзя автоматически
резать каждый непрозрачный фрагмент отдельно. По умолчанию требуется единая
подложка, которая соединяет основной рисунок и значимые капли. Контур должен:

1. включать заданную окантовку вокруг рисунка;
2. объединять близкие капли с основной наклейкой безопасными перемычками;
3. сглаживать выступы и впадины, которые плоттер не сможет надёжно вырезать;
4. удалять случайные микрофрагменты;
5. сохранять узнаваемую кляксоподобную форму.

Если отдельная капля задумана как самостоятельная мини-наклейка, это должно быть
явно указано в данных изображения.

## Раскладка

Текущий алгоритм использует прямоугольные ограничивающие рамки. Поэтому свободные
углы возле круга или кляксы пока не используются. Производственная версия должна
работать с наружными контурами, безопасным промежутком и разрешёнными поворотами.

Размер F означает вписывание в рабочую область A4, а не обязательное занятие всего
листа. Оставшееся место можно заполнять меньшими наклейками, когда контуры и
промежутки позволяют это сделать.

## Что требуется откалибровать

1. Фактический размер при печати 100% на Epson L8050.
2. Расширение и обрезание в режиме печати без полей.
3. Поля регистрационных меток Cameo 5 Alpha.
4. Ширину окантовки и минимальную безопасную перемычку для капель.
5. Минимальный промежуток между линиями реза.
6. Минимальный надёжный радиус и размер отдельной детали контура.
